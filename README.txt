STEAL A BRAINROTS SHOP — PUBLISHING NOTES

Files:
- index.html: complete responsive demo shop.

Important:
- Prices and listings are examples. Edit the products array in index.html before publishing.
- The provided “Discord invite” was a Roblox profile URL, so the site labels it as a Roblox profile and does not pretend it is Discord.
- Buy buttons open an inquiry/payment info modal. They do not process payments or automatically deliver items.
- Confirm availability and final terms before taking payment; follow Roblox and Cash App rules.

Publish with GitHub Pages:
1. Sign in to GitHub and create a new repository, e.g. sammy-brainrot-shop.
2. Upload index.html to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. After GitHub publishes it, copy the Pages URL shown in Settings → Pages. It will look like https://YOUR-USERNAME.github.io/REPOSITORY-NAME/ (this is an example format, not your actual link).

You can also use another static website host. Never enter account passwords or verification codes into a storefront.
